# 40Proejtos-TelaCarregamento

Animação de pontos para representar uma tela de carregamento, feita com HTML e CSS.

Este exercício faz parte da minha sequência de estudos de desenvolvimento web.

## Tecnologias

HTML, CSS.

## Como acessar

1. Baixe os arquivos pelo botão **Code → Download ZIP**, ou clone este repositório.
2. Mantenha as pastas e arquivos juntos e abra `index.html` no navegador.
3. Para editar, use um editor de texto ou código de sua preferência.

## Organização

- `index.html`: estrutura da página.
- `style.css`: aparência e layout.
